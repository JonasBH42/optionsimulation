# Data and replay contracts

The default source roots are `D:\QQQ\OHLCV_daily` and `D:\QQQ\raw_theta`. Readers never write to those roots. All mirrors, fixtures, manifests and reports use `qqq_sim.config.writable_path`, which confines output to `D:\optionsimulation`.

`HistoricalData.snapshot(D)` exposes completed underlying candles available at or before D and raw quotes strictly before D. The 09:30 candle first appears at 09:31. `inclusive=True` is a distinct event-time inspection mode. `events_between(start,end)` includes raw events at start and excludes raw events at end; completed candles satisfy start < availability <= end. These boundaries preserve the phase25 decision barrier and prevent already observed quotes from filling later orders.

`MarketSnapshot.quotes` contains immutable `ChainEntry` records. `quote` is the most recent valid mark, `latest_event` is the actual most recent update, and `INVALID_LATEST` prevents the earlier valid mark from masquerading as a fresh execution opportunity. Quote age, source event timestamp, optional size, relative spread, original vendor fields and optional Greek values remain available. Missing IV is distinct from zero IV. Raw source units are never guessed from future rows. The snapshot also reports the age and identity of its authoritative underlying observation.

The replay snapshot profile labels valid quotes older than60seconds as `STALE`; it retains their values for inspection. Callers may explicitly request an unfiltered view with `max_quote_age=None`, which still exposes actual age. Minute-only quote records become available at the end of their labeled minute and execute at completion phase20 before the completed-bar snapshot. Event-granular quotes retain their actual publication time and phase30 ordering. The original source timestamp remains the earliest-time bound for execution age.

The same temporal index gates last-trade observations. Event-granular publication exactly at the decision instant remains after the snapshot barrier; minute completion at that instant precedes it. A later explicit publication of a minute record uses phase30. Trade corrections and cancellations change only subsequent snapshots. A conflicting same-time last price without a reliable sequence remains null with a quality reason. Unknown condition codes can be inspected but cannot authorize execution or trade-derived volume.

The supplied real archive allows quote display using the default mapping. It does not independently establish IV units, contract deliverables, historical rates/carry or official fixing. The template `data-mapping-template.json` deliberately leaves those unknown. Explicit verified unit metadata or independent repricing evidence must establish an IV conversion. Scenario mappings must be labeled as such. `synthetic_mappings()` applies only to fixtures generated by `write_synthetic_dataset`; it must not be applied to historical archives merely to make trading or inference available.

Metadata scans do not claim that every file was validated. `audit_session` reads one selected day, reports its exact schema, SHA-256 fingerprints and underlying missing-slot coverage. A run revision binds selected raw byte hashes. Later source changes reject the bound run. Snapshot identities use causal row hashes; the separate revision preserves whole-file integrity without letting unseen future values alter the causal market state.

The November 2026 audit discovered duplicate logical OI partitions and 63 duplicate underlying dates in nested `fixed` copies. The complete duplicate report is `runtime/results/data-duplicate-partitions.json`; the bounded audit summary is `data-audit.json`. No duplicate file was silently chosen and none was modified. An OI duplication prevents known-OI computation while unambiguous quote display can continue. Duplicate underlying data prevents its affected session from being selected.

`STANDARD_US_CALENDAR_SCENARIO_V1` is the stated 2012–2030 planning calendar, including the documented holidays, exceptional closures and early closes. It is visibly marked as a scenario, not certified historical exchange data. Exact `SessionRecord` inputs override it. Calendar slots, elapsed UTC seconds and New York calendar days are separate operations. A missing expected candle remains a gap; `coverage_gap` returns the first unresolved slot.

Stored option OHLCV is the default volume source and is revealed only after its interval completes. Prior/opening `oi_before` may become known at the session open; `oi` is never intraday OI. Trade-derived volume is an explicit alternative. Trade conditions without a supplied semantic mapping are excluded from execution evidence. Corrections and cancellations affect the trade ledger prospectively when known and do not rewrite an earlier frozen snapshot.

Automatic archive download/repair is conditional in the specification and is not part of ordinary replay. The user's task did not authorize changing source archives. No repair, broker transport or external data acquisition was performed.

Probability inputs use the separate `REPLAY_QQQ_MINUTE_V1` gate from specification Section15.2: quote and IV age at most300seconds, worst-case inter-leg timestamp dispersion at most60seconds, and a current completed authoritative QQQ candle. Execution retains its stricter60second quote gate. Missing independent IV timestamps use the declared same-row observation time; explicit independent IV timestamps are checked when supplied. The job records the quality profile and measured ages in its hashed provenance.

The reference wizard has optional exact-position cash/cost overrides, dated scoped market overrides and explicit eligible session subsets. Its fixed-cost net companion is a closing-observation probability; terminal net probability remains unavailable until a terminal cost rule is supplied. Optional target/date reports come from the same reference job. The path-volatility fallback selects causal matching-expiry ATM contracts, uses separately qualified packed prices and validated vendor/scenario IVs, and records the capped weighted-median calculation. Missing compatible IVs or an unqualified basis produce a typed reason. The wizard never imports an offline inverse solver into ordinary GUI work.

The catalog checks directory metadata at most twice per second and automatically discovers added partitions. A new partition inside a bound session is a persistent revision error; it cannot silently change an existing run. A selected-file mutation remains an immediate error. Catalog publication uses atomic replacement with independent temporary files, and reuse requires the same source-root pair and normalization identity. Bounded audits enrich persisted schema fingerprints, counts, raw time ranges and quality. A mirror can register its exact identity with the catalog; changed source bytes or explicit mapping identity invalidate it.

Raw vendor Greeks remain available alongside separate normalized values. Conversion requires a recognized explicit `greek_units` declaration; unsupported conventions receive `VENDOR_GREEK_UNITS_UNVERIFIED` labels. The reader never guesses whether a Greek is per-share, per-contract, per-day or per-percent. `data-traceability.json` distinguishes these tested behaviors from unavailable historical evidence and full production acceptance. The fresh bounded real audit in `data-catalog-review.json` observed9source directories, verified original hashes unchanged, and produced the same61.18spot and40-contract10:01 snapshot for2012-06-01.

Analytic preparation now freezes these source snapshots together with complete request inputs in the session database. Results retain their original branch, state, selection and pack identities even when computation finishes after replay advances or another session opens. Pending requests and typed unavailable results are included in exports. See `analytic-records.md` for the immutable write and restore contract.
