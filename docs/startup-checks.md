The desktop runs a local preflight before opening a session. `doctor` returns the
same structured report, including the build ID and dependency versions. Checks
import the actual Qt and numerical modules, exercise New York winter/summer time
rules, validate supported configuration/event/rule versions, inspect the selected
archive roots, and check runtime storage. No package installation, download,
network call, or offline model calculation runs during these checks.

Storage checks create a small uniquely named temporary file, write and flush it,
read it back, then remove it. Every probe stays inside `D:\optionsimulation`, in
the selected runtime directories or project `.tmp`/`.cache`. Ordinary runtime
requires at least 64 MiB of free space at startup. This is a minimum startup
reserve, not an offline training budget or a promise that future writes will fit.
Read probes inspect a bounded directory sample and one source file; the normal
catalog and replay services still validate each actual partition when used.

Missing native imports, the wrong development environment, invalid calendar or
configuration versions, failed runtime writes, and insufficient disk space open
a nonmodal setup window. It lists only failed checks and corrective steps. The
application does not modify the system interpreter or attempt automatic repair.

Missing archive paths leave the desktop available for configuration or
**Session > Open synthetic demonstration**. If the underlying archive is
unavailable, a historical session is not opened automatically. Missing options
data does not prevent browsing valid underlying candles. The synthetic launch
path runs the same checks against its explicitly generated fixture roots.

A missing, unreadable, or unqualified model pack leaves browsing and simulation
available. Startup verifies the bounded manifest/validation metadata and their
hash receipts; it does not assert that the model's numerical artifacts qualify.
Normal model loading verifies all array bytes, schemas, networks, and capability
gates before any supported probability is returned. The startup dock points to
**Model > Load pack** or the explicit offline-build instructions when needed.
